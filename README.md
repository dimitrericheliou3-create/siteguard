# SiteGuard

Website uptime monitoring SaaS project.

The complete source project is provided in `siteguard-project.zip`. Download and extract the archive to access the Cloudflare Pages Functions, monitoring Worker, D1 migrations, frontend, PayPal setup guide, and release checklist.

Important: this is an MVP codebase, not production-ready yet. Review `RELEASE_CHECKLIST.md` before launch.
